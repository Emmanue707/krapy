Fixes the crash on the main screen once a desktop is paired, found on an Infinix/Transsion phone.

- the saved desktops list used a row layout that Android cannot fill as plain text, so the app closed every time it drew a paired desktop, right after the scan and on every launch after. The list now has its own two-line rows (name, then address)
- the "krapy crashed last time" dialog now opens before the list is drawn, so it can actually show up
- crash traces from the release build keep real class names and line numbers

Desktop builds are unchanged from 0.1.3 apart from the version number.

### Assets

- `krapy-0.1.4.apk` signed phone app (Android 10+). Installs over 0.1.3, pairings are kept.
- `krapy-0.1.4-linux-x86_64.tar.gz`, `-windows-x86_64.zip`, `-macos-aarch64.tar.gz` (macOS build is unsigned)
- `SHA256SUMS`
