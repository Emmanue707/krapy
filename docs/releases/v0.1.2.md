Fixes from the first real test on Fedora and an Infinix phone.

- QR scan works on dark terminals. The desktop printed the QR light-on-dark there, and the app's scanner only read dark-on-light codes, so nothing happened. The desktop now prints it black on white, the mirror window shows a big QR too, and the app reads inverted codes either way.
- the scanner shows what it is doing, uses continuous autofocus, and has "paste link instead"
- the app tells you when it can't reach the PC, and `krapy pair` prints a firewall hint if no phone shows up after 20 s
- `krapy --help` describes every command and flag
- the Vulkan `VK_EXT_physical_device_drm` warning and other wgpu noise are hidden unless you pass `-v`

### Linux install

```
tar xzf krapy-0.1.2-linux-x86_64.tar.gz
cd krapy-0.1.2-linux-x86_64
mkdir -p ~/.local/bin && cp krapy ~/.local/bin/
krapy pair
```

Leave `krapy pair` running while the phone scans.

If the phone says it can't reach the PC on Fedora:

```
sudo firewall-cmd --add-port=27183/tcp --add-port=27183/udp
```
