Small desktop fixes from the first Fedora run.

- `krapy --help` now describes every command and flag
- the Vulkan `VK_EXT_physical_device_drm` warning and other wgpu noise are hidden unless you pass `-v`
- Linux install without sudo, in the README and on the site

### Linux install

```
tar xzf krapy-0.1.2-linux-x86_64.tar.gz
cd krapy-0.1.2-linux-x86_64
mkdir -p ~/.local/bin && cp krapy ~/.local/bin/
krapy pair
```

Leave `krapy pair` running while the phone scans.
