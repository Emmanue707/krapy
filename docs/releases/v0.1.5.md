Fixes the crash when you tap a paired desktop to start mirroring, found on an Infinix phone running Android 16.

- tapping a desktop started the connection twice at the same moment: Android reports the current Wi-Fi as soon as krapy starts watching the network, and krapy took that as "network came back" and began a reconnect on top of the first connect, cutting it off
- the reconnect then raced two ways of finding the PC and stopped the slower one, and that stop closed the app. Background work now ends quietly when it is stopped, and any real error is saved instead of closing the app
- if connecting fails, the app now says why (nothing listening on the PC, firewall, a different desktop answered, lost connection) in a message and on the main screen
- stopping screen capture from the system now ends the session cleanly, and starting again while mirroring no longer shuts the new session down
- the list says "tap to mirror, hold to forget"

Desktop builds are unchanged from 0.1.4 apart from the version number.

### Assets

- `krapy-0.1.5.apk` signed phone app (Android 10+). Installs over 0.1.4, pairings are kept.
- `krapy-0.1.5-linux-x86_64.tar.gz`, `-windows-x86_64.zip`, `-macos-aarch64.tar.gz` (macOS build is unsigned)
- `SHA256SUMS`
