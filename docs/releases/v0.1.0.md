First release of krapy. *Krapy* means mirror in Jiwaka.

Low-latency Android screen mirroring over Wi-Fi and phone hotspots. Rust on the desktop, a tiny Kotlin app on the phone, QR pairing, no adb needed.

This is an early build. The protocol, decoding and adaptive bitrate are tested on loopback with a simulated phone. It has not had much time on real phones yet, so please open an issue if something breaks.

## Download

- `krapy-0.1.0.apk`: the phone app (Android 10+). Signed. Allow installs from your browser, then open it.
- `krapy-0.1.0-linux-x86_64.tar.gz`: desktop app for Linux.
- `krapy-0.1.0-windows-x86_64.zip`: desktop app for Windows.
- `krapy-0.1.0-macos-aarch64.tar.gz`: desktop app for Apple Silicon Macs (unsigned; right-click, Open the first time).
- `SHA256SUMS`: checksums.

## Use it

1. Run `krapy pair` on the computer.
2. Open the app, tap Scan QR, point it at the terminal.
3. Next time just run `krapy connect`.

`krapy doctor` tells you what is missing if it does not connect.
