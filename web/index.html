krapy

Mirror your Android screen without the lag.

Built for flaky Wi-Fi and phone hotspots. Rust desktop app, tiny Kotlin phone app. Scan a QR to pair. No adb or developer options unless you want the fallback.

Download GitHub

How it works

  1. On the desktop, run krapy pair. Keep it running while the phone scans.
  2. Open the phone app and scan the QR code on screen.
  3. Mirror starts. If the phone's IP changes, mDNS finds the desktop again on its own.

Enable remote control (Android 13+)

The APK is installed outside the Play Store, so Android blocks accessibility at first. Mirroring works without it; you only need this for desktop touch and keys.

  1. Settings > Apps > krapy.
  2. Tap the ⋮ menu (top right) > Allow restricted settings, then confirm with your PIN or fingerprint.
  3. Settings > Accessibility > krapy > turn on.

Why it is fast

  • Hardware H.264 encode on the phone.
  • UDP video with late frames dropped instead of piling up.
  • At most one frame queued on either side.
  • GPU YUV conversion on the desktop.
  • Adaptive bitrate: steps down quickly on loss, ramps up slowly when the link is clean.

Get the Android APK and the desktop app for Linux, Windows or macOS from the latest release. Install the APK on the phone, run krapy pair on the computer, scan.

Targets (not measured yet): under 50 ms glass-to-glass on good Wi-Fi; under 30 MB desktop RAM at idle.

Install on Linux

No sudo needed. Unpack the release, then:

mkdir -p ~/.local/bin && cp krapy ~/.local/bin/
krapy pair

If krapy is not found, open a new terminal or add ~/.local/bin to your PATH.
